CLI Tools

🔨
Composer
packages/composer/src/compose.ts
Resolves feature dependencies, generates schema.sql, wrangler.toml, index.ts, package.json, COMPOSITION_REPORT.md, and copies feature source files.
npm run compose -- --config examples/aussie-saver.json --output dist/aussie-saver
🚀
Deployer
packages/composer/src/deploy.ts
Full pipeline: compose → create D1 database → run schema migrations → wrangler deploy → register with validator → trigger validation run.
npm run deploy -- --config examples/wirez.json
🕵️
Drift Detector
packages/composer/src/drift.ts new
Queries live D1 via Cloudflare REST API. Compares actual tables vs schema.sql. Column-level diff with --verbose, auto-fix SQL with --fix, scan all apps with --all.
npm run drift -- --config examples/socialai.json --verbose --fix
🔎
Manifest Validator
packages/composer/src/validate-manifest.ts
Lints feature manifest.json files against the schema. Checks required fields, valid categories, route shapes, dependency references.
npm run validate-manifest -- --feature auth-bearer

+
dist/schema.sql
→
Parse expected tables + columns
CF_ACCOUNT_ID + CF_API_TOKEN
→
Query D1 REST API: sqlite_master
→
Get actual tables in live DB
Diff expected vs actual
→
missing_tables / extra_tables / column drift
--fix flag
→
Print corrective CREATE TABLE / ALTER TABLE SQL
DRIFT_REPORT.json written to output dir
·
Exit code 1 if drift detected (CI-friendly)
